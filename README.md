# Team Taskflow Manager

A modern full-stack project and task management platform built using FastAPI and React.

## Live Features

* JWT Authentication
* Protected Routes
* Role-Based Access Control
* Project Management
* Task Management
* Dashboard Analytics
* Responsive UI
* Glassmorphism Design
* FastAPI REST APIs

# Installation

## Backend Setup

```bash
cd backend

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

uvicorn app.main:app --reload
```

Backend runs on:

```bash
http://127.0.0.1:8000
```

---

## Frontend Setup

```bash
cd frontend

npm install

npm run dev
```

Frontend runs on:

```bash
http://localhost:5173
```
